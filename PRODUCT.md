# Product Context

## Purpose

This repository is an Oracle learning workspace for turning codebase study into durable memory and approachable visual artifacts.

## Current Surface

The first web surface is a basic HTML/Three.js explainer for `keijiro/KlakMath`. It translates a Unity math utility package into a web-native knowledge graph so a web developer can learn the repo through motion, nodes, and relationships rather than Unity project structure.

## Audience

- Primary: Josh, a web-oriented developer learning Unity/math concepts through familiar browser tools.
- Secondary: future Oracle sessions that need a quick visual map of what KlakMath contains.

## Success

The visitor should understand within seconds that KlakMath is a Unity.Mathematics extension package, then explore how tweening, noise, hashing, random sampling, rotation, and demos connect.
